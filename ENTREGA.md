# Entrega: Backend en Supabase

Rama dedicada a este entregable del curso **Desarrollo de Software para Plataformas Móviles** (NRC 14780).
Integrante: César Armando Reyes.

- Carpeta del entregable: `supabase/`
- schema.sql, seed.sql, políticas RLS, triggers y pruebas locales verificadas contra el stack oficial de Supabase y contra el proyecto real en la nube.

El código de la aplicación completa vive en la rama `main`; esta rama existe para que el
entregable se pueda revisar por separado, con su historia y su punto de corte propio.
